Yomiru adds Japanese learning subtitles with an English translation in
Stremio. Choose rōmaji, kana, or original Japanese.

## Try it

1. Open [Yomiru](https://yomiru.tsilva.eu) and choose **Install in Stremio**.
   You can also paste `https://yomiru.tsilva.eu/manifest.json` into
   **Addons → Add addon**.
2. Start a supported episode and select a **Yomiru** track in the subtitle
   picker. The Japanese learning line appears above the English line.
3. Enable **Style ASS subtitles** to retain the colours and sizes.

Use the [hosted library guide](docs/usage.md#hosted-library) to check available
episodes. Timing can vary by release, and dictionary-based readings can
misread names or ambiguous kanji. Original Japanese preserves source spelling.
